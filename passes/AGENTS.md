# Shared Pass Maps

This released bundle owns the default execution method for Harness and Efficiency passes.

- `harness/AGENTS.md` reviews completed ordinary work and improves a future ordinary path.
- `efficiency/AGENTS.md` reviews the immediately preceding Harness pass and improves a future
  Harness path.
- `DOCTRINE.md` files resolve uncommon placement or judgment questions.
- `PLAYBOOK.md` files resolve uncommon operating-step questions.

Start with one mode map. Load deeper files only for a named unresolved question. A target may keep a
small `docs/passes/<mode>/AGENTS.md` overlay for target-specific ownership, validation, and delivery;
it must not copy or override the shared method.
